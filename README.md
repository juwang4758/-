# 공문 자동 작성

엑셀 공문 양식은 그대로 두고, 교회마다 바뀌는 **교회명**과 **문서번호**만 자동으로 채워 PDF로 만들어 주는 작은 웹 서비스입니다. 여러 교회에 보낼 공문을 한 번에 만들 수 있고, 파일 이름도 교회마다 정해진 형식으로 붙습니다.

```bash
npm start     # 또는 node server.js → http://localhost:3100
```

외부 패키지는 필요 없습니다(Node.js만 있으면 됩니다).

## 쓰는 법

1. **설정 → 양식 파일 올리기**: 엑셀 양식에서 교회 이름이 들어갈 자리에 `[교회명]`, 문서번호 자리에 `[문서번호]`라고 적어 둔 .xlsx 파일을 올립니다.
   - 예: 수신자 칸 `[교회명] 담임목사님`, 시행 칸 `북한중보기도주간 TFT - [문서번호](2026.10.24)`
   - 시행일자도 자동으로 넣으려면 날짜 자리에 `[날짜]`라고 적습니다(예: `… - [문서번호]([날짜])`). 공문 만들기 화면에서 고른 날짜가 `2026.10.24` 형식으로 들어갑니다.
2. **공문 만들기**: 교회명을 한 줄에 하나씩 적습니다(엑셀에서 교회명 열을 복사해 붙여 넣어도 됩니다). 적은 순서대로 문서번호가 붙고, 파일 이름이 미리 보입니다.
   - **미리보기**: 첫 번째 교회의 PDF를 오른쪽에 보여 줍니다. 문서번호를 쓰지 않습니다.
   - **문서번호 발급하고 PDF 받기**: 한 곳이면 PDF 하나, 여러 곳이면 교회별 PDF를 묶은 ZIP을 내려받습니다. "PDF 한 파일로 합치기"를 고르면 인쇄용 합본 PDF 하나를 받습니다.
   - 이미 발급한 교회를 다시 적으면 표시해 주고, 발급 전에 한 번 더 묻습니다.
3. **발행대장**: 발급한 공문(문서번호·시행일자·교회명·파일 이름)이 쌓입니다. 언제든 다시 내려받을 수 있고(발급 당시 양식으로 다시 만듭니다), 엑셀(CSV)로 내려받을 수 있습니다.

## 파일 이름

기본 형식은 `[북한중보기도주간] [제목]_[교회명]`입니다. `[제목]`에는 양식에서 "제목" 칸 오른쪽에 적힌 글이 들어갑니다.

```
[북한중보기도주간] 2026년 북한중보기도주간 후원 협조 요청_한동교회.pdf
```

설정에서 형식을 바꿀 수 있습니다. 쓸 수 있는 값은 `[제목]`, `[교회명]`, `[문서번호]`, `[날짜]`이고, 그 밖의 대괄호 글자(예: `[북한중보기도주간]`)는 그대로 들어갑니다. 파일 이름에 쓸 수 없는 글자(`\ / : * ? " < > |`)는 빈칸으로 바뀝니다.

## 문서번호

- 발급할 때마다 1씩 오릅니다. 엑셀에서 쓰던 번호를 이어가려면 설정의 "다음 문서번호"에 마지막 번호 + 1을 넣으세요.
- 자릿수를 정하면 `007`처럼 앞에 0을 붙입니다.
- 번호는 서버 한 곳에서만 매기므로 여러 사람이 동시에 써도 겹치지 않습니다.

## PDF 모양

- 엑셀이 인쇄하는 방식을 따라 그립니다: 인쇄 영역(없으면 내용이 있는 범위), 여백, "한 페이지에 맞추기" 배율, 병합한 칸, 정렬, 자동 줄바꿈, 테두리, 채우기, 로고 그림(자르기 포함).
- 글꼴은 양식의 글꼴과 상관없이 **나눔명조**(바탕체와 비슷한 명조체)로 그립니다. 그래서 엑셀에서 직접 PDF로 저장한 것과 글자 폭이 조금 다를 수 있습니다.
- 나눔명조에 없는 글자(한자, 일부 기호)는 빈칸으로 나옵니다. 양식을 올릴 때와 미리보기에서 어떤 글자인지 알려 줍니다. `①`→`(1)`, `㎡`→`m²`처럼 흔한 기호는 비슷한 글자로 바꿔 넣습니다.
- 본문이 칸보다 길면 잘리지 않도록 글자를 조금씩 줄입니다.

## 환경변수

| 변수 | 뜻 |
|---|---|
| `PORT` | 포트(기본 3100). Railway가 자동으로 넣어 줍니다 |
| `GONGMUN_DATA_DIR` | 저장 폴더. 없으면 `RAILWAY_VOLUME_MOUNT_PATH/gongmun`, 그것도 없으면 `data/` |
| `GONGMUN_PASSWORD` | 정하면 접속할 때 비밀번호를 묻습니다(아이디 칸은 아무거나). 인터넷에 올릴 때는 꼭 정하세요 |

## 웹판(GitHub Pages)

서버 없이 브라우저만으로 도는 판입니다. `gh-pages` 브랜치에 올라가 있고 https://juwang4758.github.io/-/ 에서 씁니다.

- 양식·문서번호·발행대장은 **쓰는 브라우저(localStorage)에만** 저장됩니다. 다른 컴퓨터·브라우저와는 번호가 이어지지 않으니 한 컴퓨터에서 발급하세요. 브라우저 기록을 지우면 발행대장도 지워지므로, 발행대장 CSV를 가끔 받아 두세요.
- 만들기: `npm install && npm run build:web` → `site/` 폴더를 `gh-pages` 브랜치에 올립니다.
- 웹판은 서버판과 같은 화면·같은 코드(`lib/`)를 쓰고, `web/local-api.js`가 서버의 `/api/...`를 브라우저 안에서 대신 처리합니다.

## Railway에 배포하기

1. Railway에서 **New Project → Deploy from GitHub repo**로 이 저장소를 고릅니다. 시작 명령(`node server.js`)과 헬스체크(`/healthz`)는 저장소의 `railway.json`을 따릅니다.
2. **Volume**을 추가하고 Mount path를 `/data`로 정합니다. 볼륨이 없으면 재배포할 때 양식과 발행대장이 사라집니다.
3. **Variables**에 `GONGMUN_PASSWORD`(쓸 사람끼리 나눌 비밀번호)를 넣습니다.
4. **Settings → Networking → Generate Domain**으로 주소를 만들고, `https://주소/healthz`에서 `ok`가 나오는지 확인합니다.
5. `https://주소`로 들어가 비밀번호를 넣고, 설정에서 양식 파일을 올리면 끝입니다.

인스턴스는 1개로 두세요. 문서번호를 서버 한 대에서 매깁니다.

저장되는 것:

- `gongmun.json`: 설정·발행대장
- `forms/<해시>.xlsx`: 올린 양식. 발행대장에서 다시 내려받을 때 그 공문을 만든 양식을 씁니다.
